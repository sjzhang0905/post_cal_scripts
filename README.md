# Scripts

A collection of scripts for computational chemistry post-processing, data analysis, fitting, and scientific visualization.

This repository contains small, task-oriented scripts developed for practical use in computational chemistry and atomistic simulation workflows.

## Scope

The repository may include scripts for tasks such as:

- Parsing computational chemistry output files
- Extracting energies and structural information
- Processing VASP, CP2K, Gaussian, ORCA, and related calculation results
- Potential energy surface analysis
- Elastic constant and equation-of-state fitting
- AIMD trajectory analysis
- DOS, PDOS, COHP, ELF, and related data processing
- Structure and coordinate analysis
- CSV and tabular data processing
- Scientific plotting and figure generation
- Miscellaneous workflow automation

The exact set of scripts may change over time as new utilities are added.

## Requirements

Most scripts require Python 3.

Common dependencies may include:

```text
numpy
scipy
pandas
matplotlib
ase
```

Individual scripts may require additional packages. Check the script header, documentation, or error messages for specific requirements.

## Maintenance

New scripts may be added occasionally as new post-processing or plotting needs arise.

Existing scripts may also be modified when bugs are found, compatibility changes are needed, or useful improvements are identified. However, no regular release or update schedule is guaranteed.

## Disclaimer

These scripts are provided as practical research utilities.

Users are responsible for independently checking numerical results, processed data, fitted parameters, and generated figures before using them in research, publications, or production workflows.
